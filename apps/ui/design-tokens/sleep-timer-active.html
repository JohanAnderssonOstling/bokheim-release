The collapsed mobile audiobook player has no sleep timer indicator. Its title, chapter, pause, and forward controls look the same while a timer is active. Expand the player to see the timer.

03 / Timer pickers

The same quick choices, in a dropdown or bottom sheet

Desktop dropdown Opens beside the timer
Mobile bottom sheet Opens over the player or reader

Presets: 5, 15, 30, 45, and 60 minutes; End means end of chapter. Off appears only when a timer is active. Current pickers show neither a remaining-time heading nor a selected-preset highlight. The mobile book-detail player uses the shared dropdown. Long labels can overhang the app’s fixed 40 px timer buttons.

Preview scope and source references

This is an HTML reproduction of the existing Rust UI, with illustrative book content. Timer choices synchronize all examples for comparison; no audio or real countdown runs here. The app’s timed label rounds remaining seconds up to whole minutes. Reader narration shares these controls for EPUB and PDF, including the current “Chapter” label.

Appearance sources: components/audiobook.rs, components/tokens.rs, audiobook-player/dock.rs, audiobook-player/lib.rs, reader/shell/tts.rs, and theme/palettes.rs. Uses the bundled fonts, icons, and warm light/dark palettes. Desktop specimens retain their desktop width when viewed on a narrow browser; scroll within them.
